# llm-line（ドラフト）

**llm-line** は、大規模な LLM 出力を安定して取り込むための行指向フォーマット仕様です。JSON の「カンマ抜け」「括弧の閉じ忘れ」によるパイプライン停止を防ぎ、ストリーミング処理とスキーマ検証を容易にします。

**ステータス：** ドラフト / フィードバック歓迎

---

## 主要な目的
- **耐障害性：** JSON の構文崩壊を回避する。  
- **ストリーミング適性：** 行単位での低メモリ高速パース。  
- **実用性：** 正規表現を使わない Java ストリーミングパーサの参照実装を提供。  
- **拡張性：** スキーマ検証、未知タグの透過、DTO マッピングをサポート。

## 例（可読）
```

@LIST roles

- editor

@TEXT bio
John Doe is a sample user.
```

---

## なぜ llm-line か
LLM に数千のフラット項目を出力させると、わずかなフォーマットのズレで JSON が壊れ、バッチ処理が停止します。**llm-line** は括弧構造を排し、明示的なマーカーで要素を表現することで、モデルの小さな出力ズレでも機械処理が継続できるように設計されています。

---

## パーサと実装
参照実装として **正規表現ゼロの Java ストリーミングパーサ** を提供予定です。パーサは以下を満たします：
- 行単位で定常的なメモリ使用量
- レコード／リスト／テキストブロックのイベント出力
- スキーマバリデータやマッパーとの連携

（実装コードは `parser/` または別リポジトリで公開予定）
